# Как работать с кодом

1. Перед началом задачи обнови main:
   git checkout main
   git pull
2. Создай ветку под задачу:
   git checkout -b имя/задача        # пример: anya/zone-editor
3. Работай и сохраняй изменения:
   git status                        # посмотреть, что изменилось
   git add .
   git commit -m "Коротко: что сделано"
4. Отправь ветку на GitHub:
   git push -u origin имя/задача     # -u нужно только при первой отправке ветки
5. На GitHub нажми «Compare & pull request», в Reviewers выбери архитектора.
6. Если архитектор просит исправить: правь в той же ветке, делай commit и push,
   PR обновится сам.

Правила:
- одна задача = одна ветка
- напрямую в main пушить нельзя
- не коммить venv, .pt, .db, видео и снимки
