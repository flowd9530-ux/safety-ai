## Как устроена цепочка

```
main.py:  кадр → detect() → process_frame() → save_event()
               (model.py)    (rules.py)        (backend/db.py)
```

Сейчас все части — **заглушки**. Каждый владелец заменяет свою заглушку
настоящим кодом, **не меняя имён функций и формата данных**. Тогда цепочка
продолжает работать, и никому не нужно ждать соседа.

## Договорённости

### `detect(frame)` — detector/model.py · владелец 3

**Принимает:** `frame` — один кадр (сейчас это номер кадра, потом изображение).

**Возвращает:** список словарей, по одному на каждый найденный объект.
Если ничего не найдено — пустой список `[]`.

| ключ    | тип         | что значит                          |
|---------|-------------|-------------------------------------|
| `class` | str         | `"person"` или `"helmet"`           |
| `conf`  | float 0–1   | уверенность нейросети               |
| `box`   | list[int]×4 | рамка `[x1, y1, x2, y2]` в пикселях |

**Пример:**

```python
[{"class": "person", "conf": 0.9, "box": [100, 50, 250, 400]},
 {"class": "helmet", "conf": 0.8, "box": [140, 50, 210, 110]}]
```

**Заглушка сейчас:** на чётных кадрах — человек и каска, на нечётных — только человек.

**Потом:** YOLO определяет объекты на изображении.

---

### `process_frame(frame, objects)` — detector/rules.py · владелец 4

**Принимает:**
- `frame` — один кадр (сейчас номер, потом изображение);
- `objects` — список словарей из `detect()`, в том же формате.

**Возвращает:** всегда пару `(frame, events)`, где `events` — список событий.
- человек без каски → список из одного события;
- все в касках или людей в кадре нет → пустой список `[]`.

| ключ      | тип | что значит                          |
|-----------|-----|-------------------------------------|
| `type`    | str | тип нарушения, сейчас `"no_helmet"` |
| `message` | str | текст для человека                  |

**Пример:**

```python
(3, [{"type": "no_helmet", "message": "Сотрудник без каски"}])
(2, [])
```

**Сейчас:** проверяет одно правило — человек есть, каски нет.

**Потом:** каска именно на голове (по `box`), порог `conf`, зоны и другие нарушения с новыми `type`.

---

### `save_event(event, frame)` — backend/db.py · владелец 2

**Принимает:**
- `event` — **одно** событие (словарь) из списка, который вернул `process_frame()`;
- `frame` — кадр, на котором оно произошло (сейчас номер, потом изображение).

**Возвращает:** ничего — функцию вызывают ради действия, а не результата.

**Делает сейчас:** печатает строку с номером кадра и типом нарушения.

**Пример вывода:**

```
Кадр 3: нарушение no_helmet
```

**Потом:** запись события в SQLite; веб-панель получает события через FastAPI.

---

### `main.py` — точка входа · владелец 1

**Принимает / возвращает:** ничего, это запускаемый файл.

**Делает:** для каждого кадра вызывает `detect` → `process_frame` →
`save_event` для каждого события. Если событий нет, кадр просто пропускается.

**Правило:** `main.py` не знает, что внутри функций, — он только передаёт
данные дальше. Слова `person`, `helmet`, `no_helmet` в нём не встречаются.
Новые правила и классы добавляются в `detector/`, а не сюда.

**Сейчас:** кадры — это числа от 1 до 10.

**Потом:** чтение видео с камеры или из файла и передача каждого кадра по цепочке.

## Проверка

После любых изменений запусти `python3 main.py`. Вывод заглушки должен быть таким:

```
Кадр 1: нарушение no_helmet
Кадр 3: нарушение no_helmet
Кадр 5: нарушение no_helmet
Кадр 7: нарушение no_helmet
Кадр 9: нарушение no_helmet
```

Совпадает — значит, ничего не сломано.
